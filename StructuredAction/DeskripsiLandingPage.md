1. bagian yang memuat Profil dari perusahaan wifi R-NET berupa Logo,dan deskripsi

- Paket Ekonomi (Rp.165.000 / bulan) , internet cepat dan stabil, noFUP(Fair Usage Policy), unlimited Quota, untuk 3 perangkat.
- Paket Keluarga (Rp.200.000 / Bulan), Internet Cepat dan stabil, no FUP, untuk 6 perangkat.
- Paket Premium (Rp.250.000 / Bulan),internet cepat dan stabil, noFUP(Fair Usage Policy), unlimited Quota, untuk 8 perangkat.
3. bagian footer terdapat informasi mengenai kontak perushaanaan 
WhatsApp : 0813-7324-2673
Email : support@r-net.id
Jam Operasional : 24/7

pada page ini terdapat pengumuman berupa banner yang terus berjalan dari kiri ke kanan dan menempel pada bagian bawah navbar, pesan dari pengumuman diambil dari database dan disimpan di cache browser.

landing page menggunakan Taiwind cdd dan DaisyUI untuk simplysicy 

landing page menggunakan warna #366bff sebagai primary, dan #fcfcfc untuk tema light dan #1e1e1e untuk tema dark, 

gunakan tailwind css dan DaisyUi untuk Frontend, dan gunakan Laravel untuk Backend.
